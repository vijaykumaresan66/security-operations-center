About the Project

The AI SOC Analyst Dashboard is a cybersecurity monitoring platform designed to simulate a real-world Security Operations Center environment.

The application allows security logs to be uploaded, parsed, analyzed, and converted into security alerts based on predefined detection rules.

It provides SOC analysts with a centralized dashboard for monitoring security events, analyzing alerts, reviewing logs, and understanding potential security threats.
