About the Project

The AI SOC Analyst Dashboard is a cybersecurity monitoring platform designed to simulate a real-world Security Operations Center environment.

The application allows security logs to be uploaded, parsed, analyzed, and converted into security alerts using predefined detection rules.

It provides a centralized interface for monitoring security events, reviewing alerts, analyzing risk, and supporting SOC investigation workflows.
